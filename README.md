# 公式畫

把照片或影片換成一串餘弦公式，再依公式把畫面算回來。純前端，單一檔案 `index.html`，用瀏覽器打開即可。

- **圖片 → 公式**：對 Y/Cb/Cr 做二維離散餘弦展開，保留最重要的 K 項，輸出 `Y(x,y) = 116·C(0,0) + 10.6·C(1,0) - …`
- **公式 → 還原**：貼上公式（或載入 .txt）即可繪製；多幀公式會當影片播放，可輸出 PNG / 影片
- **影片 → 公式**：逐幀計算，每幀一組公式（最多 240 幀）
- **密碼（選填）**：公式本身只是編碼；設密碼後以 AES‑256‑GCM（PBKDF2）加密成密文
